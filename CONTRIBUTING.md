# Contributing (Team CSE4104-7D-T01)

## Branches
- `main`: stable, always demo-ready. No direct pushes.
- `development`: integration branch.
- `frontend`, `backend`, `ai-integration`: area branches. Create short-lived feature branches from them, e.g. `backend/jwt-auth`.

## Pull requests
- One reviewer from another member before merge.
- Use the pull request template.

## Commit messages
Good: `Added JWT authentication`, `Implemented AI chatbot integration`, `Fixed mobile responsiveness`
Bad: `update`, `done`, `work`, `final upload`

## Rules
- Commit at least weekly. Do not push the whole semester at the end.
- Never commit `.env`, API keys or real personal or medical documents. Use dummy documents only.
- Every member must understand and be able to explain the code they commit.
